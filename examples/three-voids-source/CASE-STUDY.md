# Three Voids: original production source

This is a **source-only historical snapshot**, not a runnable project or full production archive. Original scripts intentionally retain their machine paths and special cases so the implementation and revisions remain inspectable. Use the generalized tools at the repository root for new work.

The original README is a chronological handoff and includes stale intermediate-state statements. `receipts/timeline.json` is the final saved picture timeline (37 shots, 148 beats, 744.87 seconds). The two mix reports are production measurements; `receipts/youtube.md` is the upload preparation sheet, not a proof of publication.

Media, downloaded artwork/page assets, original machine configurations, fonts, samples, caches, node_modules and generated audio/video are excluded. `tools/gfx/scenes.html` is the authored scene implementation, not a scraped website. Renderers therefore reference absent inputs. See the root PROVENANCE.md for attribution and redistribution scope.
