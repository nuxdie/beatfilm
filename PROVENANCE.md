# Provenance and redistribution

The production source was recovered from the owner's Three Voids workspace on 17 November 2026. `build/` adapts its assembly, alignment, dubbing, captions, review and mixing scripts. `score/engine.py` adapts its audio engine. `examples/three-voids-source/` preserves the original project code and writing for reference. No raw footage, recordings, rendered production video, piano samples, copied artwork, browser page dumps, original machine configuration, or dependency trees are included.

The score source explicitly credits https://github.com/nuxdie/claude-music as its method/source for synthesis and album tools. Both are the owner's repositories. No blanket open-source licence is asserted by this extraction: the upstream repository did not expose a root licence when inspected. A public repository alone does not grant a licence. Establish provenance and choose a code licence before advertising the toolkit as licensed open source.

The demo's panels, cue-tone recording stand-ins and bell score are generated from code in this repository. It uses the system DejaVu Sans font without vendoring it. The production used Upright Piano KW (documented as CC0) and Salamander Grand Piano V3 by Alexander Holm (documented as CC BY 3.0); these are external dependencies, not bundled assets. Consult the original distributions before redistributing samples.

The original film references Daniel Conway's Art Block, Minecraft, community builds and map data. Their presence in a published video does not establish permission to redistribute the underlying assets in a code repository. The case study retains attribution text and source links, not those assets.
